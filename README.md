# SSAUMLT — Stock Sentiment Analysis Using Machine Learning Techniques

SSAUMLT is an end-to-end stock sentiment analysis project that combines financial news sentiment with historical stock market data to predict price movement using machine learning. The project scrapes stock-related news, preprocesses textual data, extracts sentiment signals, merges them with stock price data, trains multiple classification models, and evaluates trading-oriented performance through visualizations and risk metrics.

## What the Project Does

- Collects stock-related textual data from online sources through web scraping
- Preprocesses raw financial text using NLP techniques
- Extracts sentiment scores using a pre-trained transformer model
- Collects historical stock price data from Yahoo Finance
- Labels stock movement based on price behavior
- Trains and compares multiple machine learning models
- Visualizes buy/sell signals on stock price charts
- Computes portfolio and risk metrics such as returns, Sharpe ratio, drawdown, number of trades, and win ratio

## Workflow

### 1. Collect Textual Data
The project gathers stock-related textual data such as financial news and market-related headlines using web scraping.

### 2. Preprocess the Data
The text preprocessing pipeline includes:
- converting text to lowercase
- removing non-alphanumeric characters and digits
- tokenization
- stopword removal
- lemmatization

### 3. Extract Sentiment Scores
Sentiment is extracted using a pre-trained RoBERTa-based transformer model. The generated sentiment scores are merged into the working dataframe for downstream analysis.

### 4. Collect Stock Data
Historical stock price data is fetched using Yahoo Finance.

### 5. Label the Data
The target label is created from stock price movement:
- `1` if Close > Open
- `0` if Close < Open
- `-1` if Close = Open

The stock data is then merged with the sentiment-enriched textual dataset using the date field.

### 6. Train and Evaluate Models
The project compares multiple machine learning models, including:
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- AdaBoost
- XGBoost
- CatBoost

Evaluation is performed using common classification metrics such as:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

### 7. Visualization
Matplotlib is used to visualize stock prices along with buy and sell signals generated by the model.

### 8. Analysis and Risk Calculations
The project also evaluates trading-style performance using:
- Final portfolio value
- Total returns
- Daily mean and standard deviation
- Sharpe ratio
- Maximum drawdown
- Number of trades
- Win ratio
